M.MECHERI

Aide - Comment utiliser le site

Clique sur une question

1 Comment accéder au site ? ▶
Tape mapse.fr dans ton navigateur (Chrome, Safari, Firefox...). Le site fonctionne sur ordinateur, tablette et smartphone. Pas besoin de compte pour les cours et exercices.
2 C'est quoi mon code personnel ? ▶
C'est un code de 4 caractères (ex : KA47) donné par ton professeur. Il sert pour les devoirs notés et pour consulter tes résultats. Il est personnel, garde-le bien.
3 Où trouver mes cours ? ▶
Clique sur ta section : Cours CAP ou Cours BAC PRO. Puis ouvre la thématique (A, B, C...) et le module voulu. Le bouton bleu = Cours, violet = Révision.
4 Les boutons de couleur ? ▶
Bleu = Cours   Violet = Révision   Jaune = Exercice
Orange = Flashcards   Cyan = Auto-évaluation
Rouge = Devoir noté   Vert = Corrigé
5 Comment faire un devoir noté ? ▶
Clique sur le bouton rouge ÉVALUATION > entre ton code > lis les consignes > commence > réponds > clique Envoyer. Tu ne peux envoyer qu'une seule fois. Le copier-coller et les sorties de page sont détectés.
6 Comment voir mes résultats ? ▶
Clique sur le bouton Mes résultats en haut de cette page, puis entre ton code personnel. Tu verras tes notes et tes compétences.
7 J'ai déjà envoyé, je veux réessayer ? ▶
Si le professeur a activé la 2e chance, une demande lui est envoyée automatiquement. Un écran d'attente s'affiche. Quand il accepte, le bouton se réactive.
8 C'est quoi les 2 parcours (CAP) ? ▶
En CAP, chaque module propose un Parcours Standard et un Parcours Adapté (exercices simplifiés, plus de visuels). Ton professeur te dira lequel suivre.
9 Où sont les outils de méthode ? ▶
Utilise le Dictionnaire de la PSE pour les définitions, et la section Révision tout niveau pour les exercices et jeux.
10 C'est quoi Pause Respiration ? ▶
Un exercice de cohérence cardiaque en plein écran. Inspire 5s, expire 6s en suivant le cercle. Utilise-le avant un devoir ou quand tu es stressé.
Ce site est en constante évolution. Consulte-le souvent !
