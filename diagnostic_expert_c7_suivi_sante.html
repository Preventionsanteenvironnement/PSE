🏢 MISSION RH : ORGANISER LE SUIVI MÉDICAL

Vous êtes stagiaire dans le service RH d'une entreprise. Votre mission : analyser les profils de 6 nouveaux embauchés et déterminer leur suivi médical approprié.

📋 VOTRE DÉMARCHE D'ANALYSE :

Pour chaque salarié, vous devez déterminer :

  • Le type de visite : VIP (Visite d'Information et de Prévention) ou EMA (Examen Médical d'Aptitude)
  • Le type de suivi : Simple, Adapté ou Renforcé
  • Le calendrier : Avant prise de poste ou dans les 3 mois
