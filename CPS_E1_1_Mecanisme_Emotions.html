L'anatomie d'une émotion

Découvre ce qui se passe en toi quand une émotion arrive.

Les 4 parties d'une émotion
Le ressenti
Ce que tu sens à l'intérieur de ton corps. Toi seul le sens.
Les pensées
Les phrases qui passent dans ta tête. Personne ne les entend.
L'expression
Ce que les autres voient ou entendent : visage, voix, posture.
Le comportement
Ce que tu fais ensuite : une action.
Un exemple

Lina ouvre un réfrigérateur. Elle trouve un aliment moisi.

  • Ressenti : son estomac se soulève.
  • Pensée : « Si quelqu'un mange ça, il sera malade. »
  • Expression : son nez se plisse, sa tête recule.
  • Comportement : elle jette l'aliment et prévient les autres.

Ces 4 parties arrivent presque en même temps. Les repérer aide à comprendre ce qui se passe en toi.

Je m'entraîne : trier les indices
Le chemin d'une émotion

Une émotion ne surgit pas de nulle part. Elle suit toujours le même chemin :

Déclencheur
→
Ce que je ressens
→
Besoin touché
→
Ce que je fais
  • Déclencheur : ce qui arrive.
  • Ce que je ressens : d'abord dans le corps, puis le mot de l'émotion.
  • Besoin touché : ce qui compte pour moi à ce moment.
  • Ce que je fais : mon action.

Pour chaque phrase, choisis sa place dans le chemin.

À retenir
✓ Une émotion se sent dans le corps : ventre, gorge, cœur, chaleur.
✓ Elle s'accompagne de pensées automatiques.
✓ Elle se voit aussi de l'extérieur : visage, voix, posture.
✓ Elle suit un chemin : déclencheur → ce que je ressens → besoin touché → ce que je fais.
