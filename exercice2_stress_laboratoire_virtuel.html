🎯 CORRECTION DÉTAILLÉE

✅ ASSOCIATIONS CORRECTES :
Phase d'ALARME : Accélération cardiaque + Augmentation vigilance + Libération glucose
Phase de RÉSISTANCE : Tensions musculaires chroniques
Phase d'ÉPUISEMENT : Fatigue chronique + Affaiblissement immunitaire
💡 EXPLICATION SCIENTIFIQUE :
Phase d'alarme : L'hypothalamus stimule les surrénales → sécrétion d'adrénaline → effets immédiats (tachycardie, hypervigilance, mobilisation énergétique).
Phase de résistance : Sécrétion continue d'adrénaline + cortisol → maintien de l'adaptation → tensions musculaires persistantes.
Phase d'épuisement : Saturation des systèmes adaptatifs → épuisement des ressources → pathologies (fatigue, immunodépression).
