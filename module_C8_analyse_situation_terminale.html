Étape 1 : Qualification des événements

Compétence C2 : Pour qualifier un événement, vous devez analyser :
  • Thomas : Accident du travail ✓ (événement soudain, sur lieu de travail, pendant horaires)
  • Sarah : Maladie professionnelle ✓ (exposition chronique, lien avec l'activité professionnelle)
💡 Pour progresser :

Retenez les 3 critères AT : soudaineté + lieu/temps de travail + lésion. Pour les MP : exposition chronique + tableaux officiel + délai de prise en charge.

Étape 2 : Procédures de déclaration

Compétence C4 : Démarches AT vs MP :
  • AT (Thomas) : Toutes les réponses sont correctes ✓
  • MP (Sarah) : Toutes les réponses sont correctes ✓
💡 Pour progresser :

Mémorisez : AT = 24h + 48h / MP = 15j + CMI. Ces délais sont cruciaux pour l'indemnisation.

Étape 3 : Calcul d'indemnisation

Compétence C5 : Calculs corrects :
  • 28 premiers jours : 59,17€ × 60% × 28 = 995,64€ ✓
  • 7 derniers jours : 59,17€ × 80% × 7 = 331,15€ ✓
  • Total : 1326,79€
💡 Pour progresser :

Formule clé : Salaire brut / 30,42 = salaire journalier. Puis 60% (28j) et 80% (à partir 29e j).

Étape 4 : Responsabilités employeur

Compétence C6 : Éléments attendus dans votre rapport :
  • Échafaudage : Faute inexcusable possible, responsabilité pénale (non-respect règles sécurité)
  • Solvants : Obligation de prévention, formation, EPI, surveillance médicale
  • Conséquences : Majoration rentes, dommages-intérêts, amendes
💡 Pour progresser :

L'employeur a une obligation de sécurité de résultat. Distinguez responsabilité civile (réparation) et pénale (sanction).
